# CarmNote SNA Documentation

This documentation applies to the compiled CarmNote SNA release distributed
in this repository.

## Start here

1. [User guide](./USER-GUIDE.md) — prepare an edge list, build a graph, run
   analyses, export, save, and share.
2. [Menus and interface](./MENUS-AND-INTERFACE.md) — every File, header, data,
   cell, visualization, export, and lock control.
3. [Cell reference](./CELL-REFERENCE.md) — every cell exposed in the notebook
   header, in interface order.
4. [Carm Research License](https://github.com/mohsaqr/carm-license) — the
   canonical license, version history, and third-party notices.
5. [Downloads and versions](./DOWNLOADS-AND-VERSIONS.md) — the final guide,
   defining the full and minified files.

## Recommended reading paths

### First-time user

Follow the [User guide](./USER-GUIDE.md). Use the menu and cell references
when a control or method is unfamiliar, then consult
[Downloads and versions](./DOWNLOADS-AND-VERSIONS.md) for the file definitions.

### Researcher preparing a reproducible analysis

Read the saving, locking, and sealing sections in
[Menus and interface](./MENUS-AND-INTERFACE.md), then use the
[Cell reference](./CELL-REFERENCE.md) to record each source network and
analysis setting.

### Instructor or collaborator

Use the full build, keep an editable saved copy, distribute a locked or sealed
copy, and share this documentation separately from the notebook file.

## Documentation scope

The documents describe the current public release and its visible interface.
Older saved notebooks may contain compatibility cells that are not currently
offered in the header.
